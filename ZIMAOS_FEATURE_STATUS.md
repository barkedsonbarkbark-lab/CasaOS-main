# ZimaOS-inspired feature status

This repository is based on CasaOS Main. The following are targets, not magically inherited features:

- Dashboard/UI redesign: requires CasaOS-UI work
- App Store/app lifecycle: primarily CasaOS AppManagement + UI
- Files/storage: available through CasaOS services; integration must be tested as a complete bundle
- Gallery/timeline/map/AI search/memories: requires a dedicated UI/data/indexing implementation
- RAID/fan/GPIO/AMD telemetry: hardware-specific implementations are required
- Spotlight/global search: requires indexing/search UI work

Do not describe this repository as a complete ZimaOS replacement until these components are implemented and tested together.
